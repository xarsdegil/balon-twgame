## Short description

A simple Twitch chat game where viewers take turns inflating a balloon until someone makes it pop.

## Description

**Chat Balloon** is a small Twitch chat game made for streamers who want an easy way to involve their viewers. There are no accounts for viewers to create and no complicated rules to explain.

After the streamer signs in with Twitch, viewers can type `!inflate` in chat to join the queue. Their names appear beneath the balloon as they take turns making it bigger. Nobody knows exactly when it will pop, so every turn has a little risk. When it finally bursts, the game announces the viewer responsible in chat and starts a new round.

The game uses a compact square window that fits neatly into an OBS layout. Hover over the window to open the settings, where you can change the command, balloon and background colors, queue size, cooldown, inflation range, player-name visibility, and the message sent after a pop. A transparent background is available for compatible capture setups, and any solid color can be selected for chroma keying.

Getting started is straightforward:

1. Download and extract the Windows build.
2. Run `Chat Balloon.exe`.
3. Select **SIGN IN WITH TWITCH** and approve access in your browser.
4. Add the game window to OBS or your preferred streaming software.
5. Let viewers join with `!inflate`.

You can also test the game locally before going live. Press `Space` to add one test viewer, `A` to add five, or `P` to make the balloon pop on the next turn.

Chat Balloon needs Windows, an internet connection, and a Twitch account. It requests permission to read and send chat messages only for receiving commands and announcing the result. The saved Twitch session and game settings stay on the local computer.

This is an early release, so feedback about stream setup, chat behavior, queue rules, and overlay usability is welcome through the itch.io community page.
